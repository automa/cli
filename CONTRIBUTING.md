# How to Contribute

## Prerequisites

- Have [`rust` & `cargo`](https://www.rust-lang.org/) installed.
- Have [`clippy`](https://github.com/rust-lang/rust-clippy) installed.

## Installing dependencies

```sh
cargo check
```

## Running the tool

```sh
cargo run
```

## CI/CD

#### Testing

```sh
cargo test
```

#### Linting

```sh
cargo lint
```

#### Formatting

```sh
cargo format
```
